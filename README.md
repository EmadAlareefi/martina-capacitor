# Martina Capacitor

Native iOS and Android wrapper for `https://martina.sa` using Capacitor.

## What This Project Does

- Loads the production Martina Next.js app in a native WebView.
- Uses bundle/package ID `sa.martina`.
- Includes native iOS and Android projects generated by Capacitor.
- Enables the native push notification bridge used by the Next.js app.

## Required External Setup

1. Create a Firebase project.
2. Add Android app `sa.martina` and place `google-services.json` at:
   `android/app/google-services.json`.
3. Add iOS app `sa.martina` and place `GoogleService-Info.plist` at:
   `ios/App/App/GoogleService-Info.plist`.
4. In Apple Developer/Xcode, enable Push Notifications for the app target.
5. Upload the APNs auth key to Firebase Cloud Messaging.
6. Add the Firebase service account JSON to the Next.js app as base64:
   `FIREBASE_SERVICE_ACCOUNT_JSON_BASE64`.

## Commands

```bash
npm run sync
npm run open:android
npm run open:ios
```

## Implementation Notes

- The web runtime is remote: `https://martina.sa`.
- `www/index.html` is only an offline/fallback shell required by Capacitor.
- Payment redirect hosts for MyFatoorah, Tabby, and Tamara are allowed in `capacitor.config.json`.
- Transactional push registration and sending live in the sibling `martina-nextjs` project.

## Validation Checklist

- Android opens Martina and completes OTP sign-in.
- iOS physical device opens Martina and completes OTP sign-in.
- After sign-in, a token is stored by `/api/push/register`.
- Firebase test push arrives on both platforms.
- Tapping an order notification opens the matching order route.
- Checkout redirects work for COD, MyFatoorah, Tabby, and Tamara.
